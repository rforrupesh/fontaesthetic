In addition to standard PNG format, there is also a ‘[stylish text](https://aestheticfonts.in/blog/what-is-aesthetic-font/)’ PNG format . This enables stylish text to be added to images, including thumbnails, banners and social media content – without the background image being in a box. For example, text such as a name, slogan, username and/or caption, can be transformed into an image and overlaid on top of another image.

Thanks to a transparent background, this is achievable. Compared to standard PNGs which display the whole box, the stylish text PND Image ensures that the text remains visible and that the surrounding area remains transparent.

## How to Design Stylish Text PNGs

A stylish text PNG can be designed by choosing and customising the font and then removing the background. These steps can all be undertaken in any online word processor or design tool which has the ability to save in PNG format.

1. Add text – add text such as your name, moniker, heading and/or quote.
2. Decide on the font – opt for a calligraphy, bold, serif and/or script font or any stylish font.
3. Customise the font – define the font size, colour and positioning and apply effects if required.
4. Remove/choose transparent background – either deselect the background or select the transparent background option.
5. Save as a PNG – save the text based image ensuring that the transparent background option is selected.

There is also a specific tool – [Font Generator](https://aestheticfonts.in/) – which can be used to produce stylish text in a variety of Unicode font formats. Once generated, this text can then be copied and added to your favoured editing programme.

However, when it comes to image fonts, standard [font libraries](https://aestheticfonts.in/blog/free-fonts/) provide greater flexibility regarding font customisation. This includes the ability to alter the font thickness, letter spacing and size, amongst other options.

## How to Make Text PNG with a Transparent Background

Text can then be placed on top of images, banners and other graphics without having to place a box over the top of the image. This is done by using alpha channels which are used in PNGs to control the level of transparency of an image.

To produce a transparent PNG, remove the background in your image programme and then export the image as a PNG. This will then let the image behind show through. Pixels which have partial transparency will also help to give text clearer borders.

It should be noted that transparency does not mean a white background. Should a white box appear over an image when trying to overlay an image onto another image, this is due to incorrect export settings being applied.

## How to Add Fancy Text to a Photo

Clear text, in PNG format can then be overlaid onto images, so that the background is still legible. For example, cursive text could be added to a portrait image, a bold font to a YouTube thumbnail and fancy text to a advert, again, without changing the original image.

1. Open the [image you wish to add text to](https://aestheticfonts.in/add-text-to-photo/).
2. Add a new layer containing your stylish text PNG.
3. Position and scale the text.
4. Change the colour, border and/or effects of the text.
5. Save your new image.

Prior to saving, check that the text has suitable levels of contrast. As previously mentioned, pale text will not show up well in light sections of an image and dark text will merge in with the darker sections.

## **Frequently Asked Questions**

### How do I make fancy text PNGs?

Write and edit text using an online design tool, and then generate a PNG file with a transparent background.

### How do I save fancy text with a transparent background?

Within an image editing programme turn off the background and save your creation in PNG format so that the transparent sections remain.

### Why is there a white background on my PNG?

This may be because the base of the canvas is set to white. Turn off the background and then save your design in PNG format.

### Can I apply fancy text to images?

Yes. Open a new layer within an image editing programme and import your transparent PNG. Then you can move and scale the text so that it is suited to your image.

### Can I make fancy text PNGs on my phone?

Yes. There are text and image design apps which are suitable for mobile phones. Create fancy text, save it in PNG format and then overlay it onto images, thumbnails and social media graphics.

### Is it possible to copy text from a PNG?

No. As a PNG is essentially a picture, the text is made up of pixels and cannot therefore be copied. However, [Optical Character Recognition](https://www.ibm.com/think/topics/optical-character-recognition) (OCR) can be used to analyse and then copy text from a PNG. To copy fancy text, however, a Unicode font generator should be used.
