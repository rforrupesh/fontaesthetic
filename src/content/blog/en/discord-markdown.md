## Discord

Want to make your Discord messages look more interesting and easier to read? You can use Discord Markdown to format your text without installing any extra tools.

> Discord supports simple formatting options such as **bold**, *italic*, underline, strikethrough, spoilers, code blocks, and more. You only need to add a few special characters before and after your text.

In this guide, you will learn how to use Discord Markdown, format messages, and create stylish text using a free text formatter.

## What Is Discord Markdown Text Formatting?

Discord Markdown is a simple text formatting system. It lets you change how your messages look by adding special characters around words or sentences.

For example, you can type `**Hello**` to make the word appear in bold.

Discord uses Markdown for many common formatting options, so you can make your messages stand out while chatting with friends or posting in servers.

## What Is Markdown?

[Markdown](https://en.wikipedia.org/wiki/Markdown) is a simple text formatting language that uses special characters to change how text looks. Instead of clicking buttons, you type symbols around your text to make it **bold**, *italic*, or ~~strikethrough~~.

it is lightweight markup language created by `John Gruber` in 2004 that lets you format plain text using simple keyboard symbols instead of complex HTML tags or visual editor buttons

## How to Make Bold Text in Discord

Bold text is useful when you want to highlight an important word, announcement, or message.

To make text bold, add two asterisks (`**`) before and after your text.

**Example:**

```md
**Hello Discord!**
```

**Result:** **Hello Discord!**

You can use bold text for server announcements, important instructions, reminders, and headings.

## How to Make Italic Text in Discord

Italic text gives your message a slightly different appearance. It is useful for emphasis or adding a different tone to your words.

To make text italic, use one asterisk (`*`) or one underscore (`_`) on both sides.

**Example:**

```md
*Hello Discord!*
```

**Result:** *Hello Discord!*

You can also use underscores:

```md
_Hello Discord!_
```

## How to Underline Text in Discord

Underlined text can help draw attention to a specific word or sentence.

To underline text, add two underscores (`__`) before and after it.

**Example:**

```md
__Hello Discord!__
```

**Result:** <u>Hello Discord!</u>

This formatting can be useful for highlighting important information in a message.

## How to Make Strikethrough Text in Discord

Strikethrough text adds a line through your words. You can use it to show corrections, jokes, or something that is no longer relevant.

To use strikethrough, add two tildes (`~~`) around your text.

**Example:**

```md
~~This message is incorrect.~~
```

**Result:** ~~This message is incorrect.~~

## How to Combine Bold, Italic and Underline Text

Discord also lets you combine multiple formatting styles in one message.

Here are some useful combinations:

| Formatting | Markdown syntax | Example |
|---|---|---|
| Bold Italic | `***text***` | ***Hello*** |
| Underline Bold | `__**text**__` | <u>**Hello**</u> |
| Underline Italic | `__*text*__` | <u>*Hello*</u> |
| Underline Bold Italic | `__***text***__` | <u>***Hello***</u> |

Just place the correct Markdown characters around the text you want to format.

## How to Create Headers in Discord Messages

Headers make longer Discord messages easier to read. They can be useful for server updates, guides, and organised announcements.

Discord supports different header sizes using the hash (`#`) symbol at the beginning of a new line.

**Examples:**

```md
# Main Heading
## Smaller Heading
### Small Heading
```

Add a space after the hash symbols before writing your heading.

## How to Use Subtext in Discord

Subtext makes a line appear smaller than normal message text. It can be useful for notes or additional information.

To create subtext, add `-#` followed by a space at the beginning of a line.

**Example:**

```md
-# This is a small note.
```

Make sure `-#` appears at the beginning of the line.

## How to Create Masked Links in Discord

Masked links let you display clickable text instead of showing a full URL. This can make your messages look cleaner.

Use square brackets for the displayed text and parentheses for the link.

**Example:**

```md
[Visit Discord](https://discord.com/)
```

The message will display the words "Visit Discord" as a link.

## How to Create Lists in Discord

You can use Markdown to create simple lists in Discord messages. Lists are useful for sharing rules, instructions, and important points.

Use a hyphen (`-`) or an asterisk (`*`) followed by a space to create a bullet point.

**Example:**

```md
- First point
- Second point
- Third point
```

You can also create a nested list by adding two spaces before a bullet point.

```md
- Main point
  - Sub point
  - Another sub point
```

## How to Use Code Blocks in Discord

Code blocks help display text in a separate formatted area. They are useful for sharing programming code, commands, or text that should keep its spacing.

For a short piece of code, place one backtick on both sides.

**Example:**

```md
`console.log("Hello");`
```

For multiple lines, use three backticks before and after the text.

**Example:**

````md
```
This is a code block.
You can write multiple lines here.
```
````

## How to Use Block Quotes in Discord

Block quotes help separate quoted text from the rest of your message.

To create a single-line quote, add `>` and a space before your text.

**Example:**

```md
> This is a quoted message.
```

For a multi-line quote, use `>>>` at the beginning.

```md
>>> This is the first line.
This is the second line.
This is the third line.
```

## How to Use Spoiler Text in Discord

Spoiler formatting hides part of your message until someone chooses to reveal it. It is useful when discussing movie endings, games, or story details.

To hide text, add two vertical bars (`||`) before and after the content.

**Example:**

```md
||This is a hidden spoiler.||
```

The text will remain hidden until the reader reveals it.

## Discord Markdown Formatting Cheat Sheet

Here is a quick reference table of useful Discord Markdown commands.

| Formatting | Syntax | Purpose |
|---|---|---|
| Bold | `**text**` | Makes text bold |
| Italic | `*text*` | Makes text italic |
| Underline | `__text__` | Underlines text |
| Strikethrough | `~~text~~` | Adds a line through text |
| Bold Italic | `***text***` | Combines bold and italic |
| Header 1 | `# text` | Creates a large heading |
| Header 2 | `## text` | Creates a smaller heading |
| Subtext | `-# text` | Creates smaller text |
| Spoiler | `\|\|text\|\|` | Hides text |
| Inline Code | `` `text` `` | Formats inline code |
| Block Quote | `> text` | Creates a quote |

Keep this table handy when you need to format Discord messages quickly.

## Markdown vs Unicode Text Formatting in Discord

Markdown and Unicode text formatting are two different ways to change how your text looks.

**Markdown** uses special characters to format normal text. For example, `**Hello**` makes your message bold.

**Unicode text styles** use different characters that look like decorative letters. For example, `𝐇𝐞𝐥𝐥𝐨` uses bold-style Unicode characters.

Here is a simple comparison:

| Feature | Markdown | Unicode Text |
|---|---|---|
| Bold text | Yes | Yes, with bold-style characters |
| Italic text | Yes | Yes, with italic-style characters |
| Fancy styles | Limited | Many styles |
| Special symbols | No | Available in some styles |
| Copy and paste | Yes | Yes |

Use Markdown when you want standard message formatting. Use Unicode styles when you want a more decorative look.

Keep in mind that Unicode styles are not actual font files. They use different text characters, and some characters may look different or may not be supported on every device.
