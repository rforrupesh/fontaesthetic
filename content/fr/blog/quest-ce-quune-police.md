Une police est un ensemble de caractères qui partagent un même design. Les polices traditionnelles sont des fichiers installés sur un appareil. Le texte stylé en unicode, comme celui généré par cet outil, utilise des points de code unicode déjà stylisés — aucun fichier ni installation requis, il fonctionne donc partout où du texte brut fonctionne.
